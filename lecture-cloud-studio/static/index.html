아이폰·아이패드용 무료 오프라인 Whisperkit 앱에서 녹음 파일을 전사한 다음 JSON으로 내보내기 → 위 파일 칸과 PDF를 넣으세요. Whisper 전사본이 있으면 오디오를 함께 올려도 Cloud Speech 재인식은 건너뜁니다. (현재 PDF 그림 인식은 아직 미구현입니다.)

음성 파일은 브라우저에서 비공개 Cloud Storage로 직접 업로드되므로 Cloud Run의 일반 업로드 용량 제한을 피합니다. 서버가 오디오를 약 18분 단위로 자동 분할합니다. 이 앱은 환자 개인정보가 포함된 기록용이 아닙니다.
